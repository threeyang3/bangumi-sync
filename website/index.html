WHAT IT DOES

不只是同步。
让收藏成为自己的资料库。

既能轻松导入第一批收藏，也能长期管理不断增长的作品笔记。

⇄01 / SYNC

收藏与状态同步

比较本地与 Bangumi 的评分、标签、短评、收藏状态和章节进度，按字段选择同步方向。

支持全面同步与增量同步
▧02 / MARKDOWN

本地笔记，自由编辑

收藏落地为普通 Markdown 文件。Frontmatter、正文和自定义属性都可以按自己的习惯整理。

与 Obsidian 工作流衔接
✳03 / TEMPLATE

统一的模板系统

作品分类树、内容模板与路径规则分别继承，支持内置预设、Markdown 文件和自定义内容。

可预览、导入、备份模板
⌘04 / CONTROL

集中管理收藏

使用控制面板筛选、搜索、快速打开条目，或在确认后进行批量编辑与封面管理。

搜索添加与批量处理
▣05 / PROGRESS

逐集记录进度

在笔记中查看章节列表与标记状态，追踪动画、漫画及相关作品的观看或阅读进度。

保留未选择的章节记录
◇06 / RECOVERY

重视本地文件安全

写入前检查数据变化，遇到异常时提供本地事务恢复机制，尽可能避免意外覆盖。

GET STARTED

让收藏进入 Obsidian。

安装并启用插件，几分钟内完成基本配置。

推荐

通过 GitHub Release 安装

  1. 下载文件从同一版本的 Release 下载 main.js、manifest.json 和 styles.css。
  2. 放入插件目录将三个文件放到 Vault 中的以下目录。.obsidian/plugins/bangumi-sync/
  3. 启用插件进入 Obsidian「设置 → 社区插件」，启用 Bangumi Sync。
  4. 连接 Bangumi获取并填入 Access Token，选择同步方式，即可开始使用。

GOOD TO KNOW

你可能还想了解。

有关存储方式、插件依赖和同步保护的几个常见问题。

在 GitHub 提问 ↗
我的收藏会存在哪里？

插件将条目保存为 Obsidian Vault 内的普通 Markdown 文件。你可以用 Obsidian 或其他文本编辑器继续整理，不依赖专有数据库才能读取正文。

需要安装 Dataview 吗？

默认模板包含 Dataview 内联查询。建议安装并启用 Dataview 以正确显示这些动态字段；即使未安装，Markdown 源文件仍然存在。

修改模板会自动更名或覆盖旧笔记吗？

不会因为修改模板就自动迁移已有文件。路径变化请使用插件提供的诊断与路径迁移预览；同步时仍以 Bangumi Subject ID 识别条目。

可以从 Obsidian 同步回 Bangumi 吗？

可以针对评分、短评、标签、收藏状态及章节进度等支持的字段选择同步方向。插件会在执行前复核相关数据；云端与本地跨系统更新不能保证完全原子化。

这个插件免费且开源吗？

是的。项目以 MIT 许可证开源，源码、版本说明、问题反馈和安装文件均可在 GitHub 查看。
