# 6.14.1

## 修复

- 修复章节状态列表含引号等合法 YAML 写法时被漏读的问题。局部章节修改保留未选章节；同步不再因漏读而误清除云端状态。
- 修复普通“同步状态”继续使用过期云端预览的问题。执行前复核选中条目的收藏及相关章节／平台数据，数据变化或无法读取时中止并要求重新比较。

## 改进

- 非法章节状态、重复章节 ID 或非列表属性会明确报错，不再静默解释为空状态。
- 普通状态同步冻结本次确认的字段选择，并检查账号变化。复核最多并行处理三个条目，跳过条目不发请求，全面同步不重复执行已有预检。
- 通过自动化回归、生产 Obsidian 隔离环境及专用测试账号的评分拉取、写回与过期预览测试。测试评分已恢复，未选字段保持不变。

写前复核会增加所选条目的必要读取请求；校验后的外部变化仍可能与写入交错。本地回滚不能撤销已经成功写入 Bangumi 的修改。实体 iOS／Android 未在本轮测试。
