# 6.15.2

## 修复

- 模板备份现在将启用的文件模板内容快照存入 manifest，支持同一 Vault 或跨 Vault 恢复。
- 导入提供“仅恢复规则”和“恢复规则及模板文件”。文件恢复创建新目录并重新绑定引用，保留原文件与未激活草稿。
- 应用前预检全部有效模板，显示缺失引用、空白／条件结构错误及受影响分类；有错误时阻止导入，并可重新选择文件。

## 改进

- 导入前自动备份当前配置，应用时再次检查模板和配置是否发生变化。
- 真实 ID 预览明确提示未加载个人收藏评分、短评、标签及个人章节进度。

旧版 manifest 可继续恢复规则；没有内嵌快照时，请重新选择随包导出的 Markdown。文件恢复失败产生的新目录保留，便于检查。
