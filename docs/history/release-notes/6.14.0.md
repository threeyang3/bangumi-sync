# Bangumi Sync 6.14.0

本版增加全面同步，并补齐预览新鲜度、身份识别、撤销和导入的安全边界。

## 新功能

- 全面同步一次比较当前账号全部收藏，按字段审阅已有笔记差异，并选择导入缺失笔记。本地独有笔记保持不变。
- 执行前复核所选条目的云端数据、本地内容和新增身份；数据过期、身份冲突或无法复核时，在首次写入前停止并要求重新比较。

## 改进

- 扫描目录留空时从默认及各类型模板推导共同根目录，统一控制面板、同步和导入／导出范围；配置不一致或目录异常时明确提示。
- 控制面板同时保留全面同步与恢复入口，插件弹窗样式隔离，恢复诊断默认折叠，失败提示保持可见。
- 已失效的预览只提供刷新和关闭；执行前的属性表单失败或取消仍可重试有效预览。
- 校验与详情读取受共享并发限制，列表分页展示；普通状态比较不增加章节目录请求。

## 修复

- 批量撤销拒绝覆盖后续编辑，文件移动或消失时报告未完成，并保留部分恢复进度供重试。
- 用户数据导入在实际写回时检查原始内容，避免覆盖并发编辑。
- 章节局部更新保留范围外标记；本地取消章节标记能向云端发送清除状态，部分上传失败不再计为完全成功。
- 完整读取章节分页，接受合法的零总数空响应，并保留对缺页、重复 ID 和异常总数的检查。
- 搜索空页停止无进展分页，迟到响应不会覆盖新的搜索结果。
- 单条收藏无法复核时提示可能的账号可见性／NSFW 限制，继续阻止写入。

## 使用边界与升级

- **本地导入回滚不会撤销已经成功写入 Bangumi 的修改，也不会撤销此前完成的状态更新。** 部分成功后请检查结果，失败不表示所有操作都已还原。
- 写前复核无法阻止其他设备在复核完成后继续修改云端；Bangumi 与 Vault 不构成跨系统原子事务。
- 改变模板根目录前，让扫描范围覆盖旧、新目录；填 `/` 可选择整个 Vault。扫描范围之外的历史笔记不会被自动发现或移动。
- 509 项自动化测试及生产 Obsidian 隔离沙盒验证通过。专用账号的真实 API 冒烟覆盖评分双向同步、过期预览拒绝、缺失笔记导入，以及注入详情失败后的回滚和重新导入；测试评分已还原。
- 手机端证据仍为桌面窄屏模拟，尚未完成实体 iOS／Android 测试。
- 最低 Obsidian 版本为 1.8.7。升级前备份 Vault，下载同一 Release 的 main.js、manifest.json、styles.css，替换插件目录中的对应文件并重载。
