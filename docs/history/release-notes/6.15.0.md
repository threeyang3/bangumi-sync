# 6.15.0

## 新功能

- 统一作品模板分类树：五个大类、三个书籍分组和 25 个细分类别，共用内容与路径设置入口。
- 内容与路径独立继承，直接查看有效来源；自定义草稿和文件引用在切换来源后保留。
- 支持只读 Markdown 与首选路径预览，可使用示例或真实 Bangumi 条目 ID。
- 模板管理提供验证、唯一目录导出、manifest 导入及导入前自动备份。

## 改进

- 自动迁移旧模板、路径与共享笔记配置，保留旧字段作为备份；不会自动改写或移动已有笔记。
- 引用模板文件变化后自动刷新运行时快照，并使旧预览失效；活动事务继续使用原快照。
- 共享笔记独立管理；桌面窄窗口采用单列模板工作区。

## 修复

- 修复少年漫画等元数据误选小说模板，以及跨大类同名分类串用模板。
- 导出不再覆盖已有文件；缺失、空白或条件结构不完整的模板阻止受影响条目生成，不再静默回退。
- 修复模板预览的文件路径规范化与插件卸载后的弹窗清理。

预览展示新建正文与首选路径；收藏状态、本地内容保护、封面下载及批量碰撞分配仍以同步流程为准。跨 Vault 导入后，文件引用需按目标 Vault 重新选择。实体移动设备尚未验证。
