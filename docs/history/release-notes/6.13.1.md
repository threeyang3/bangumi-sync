# Bangumi Sync 6.13.1

本版改进桌面与手机端操作体验，修复连续编辑和搜索状态问题，并减少界面更新的重复工作。

## 改进

- 控制面板保留四个主要入口，其余操作统一放入“更多”；手机端筛选可展开，触摸按钮和选择区域更易操作。
- 批量编辑显示字段名称，导入和状态对比明确标注数据来源；恢复界面优先显示影响和可用操作。
- 搜索结果先显示，再逐项确认收藏状态；确认失败可单独重试，更改类型或排序会从第一页重新查询。
- 搜索状态更新复用封面与标题，表格离屏构建并减少冗余节点；清空或关闭搜索释放结果引用，相同条件不重复查询。

## 修复

- 保存云端收藏后再次编辑使用刷新后的数据，避免旧评分或标签覆盖新值。
- 取消编辑不会污染原有标签；评分初始数值与滑块一致。
- 清空、关闭或更换搜索后，过期响应不再覆盖当前结果；重复加载和失败重试不会跳页。
- 窗口缩放时保留条目信息、已选条目和分页；修复手机弹窗溢出、样式影响其他插件及键盘操作问题。

## 验证与升级

- 405 项自动化测试通过，已在 production Obsidian Sandbox 验证编辑、撤销、搜索、权限门控及响应式布局。
- 同机性能对照中搜索状态更新中位耗时下降，桌面表格基本持平；不承诺所有设备和场景均提速。
- 手机测试为桌面窄屏模拟，尚未验证 iOS／Android 真机；网络验证使用固定数据，未执行真实账户云端写入。
- 最低 Obsidian 版本仍为 1.8.7。下载本 Release 的 main.js、manifest.json、styles.css，替换插件目录内同名文件并重载插件。
