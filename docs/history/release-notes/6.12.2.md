# Bangumi Sync 6.12.2

## Performance

- 大批量同步收尾时，恢复日志通过预先建立的路径索引匹配文件，减少重复遍历和路径规范化带来的主线程阻塞（Issue #22）。
- 恢复日志事实使用增量索引，相同事实复用快照，变化时才复制对应数组。
- 原文快照复用 SHA-256 计算，普通恢复日志使用紧凑 JSON，减少重复计算和序列化体积。

## Validation

- 306 项自动化测试通过；真实 Obsidian 隔离测试库覆盖 1303 条记录、并发 5 的新建和更新，逐条检查正文。
- 验证日志写入失败时阻止笔记修改，以及插件重载后的恢复回滚。
- 本机合成数据补测中新建收尾计算约 4757.9 ms → 8.6 ms；实际整体同步速度仍受正文规模、网络、磁盘和后台调度影响。

## Compatibility and testing

- 最低 Obsidian 版本仍为 1.8.7；没有新增配置项或恢复日志 schema 迁移。
- 保留每次笔记修改前完整持久化恢复日志、日志轮转和失败阻断。
- 可在 Obsidian 社区插件设置中检查更新并安装 6.12.2，再使用原有收藏和并发设置复测。手动安装时，将本 Release 的 main.js、manifest.json、styles.css 放入 Vault 的 .obsidian/plugins/bangumi-sync/，然后重载插件。
- 本机测试未使用 Issue #22 报告者的原始数据或 Performance trace；欢迎反馈实际写入和收尾耗时，不能仅凭合成测试保证消除全部同步卡顿。
