# 6.13.1 release validation

Release preparation: 2026-10-21. Integration: PR #32 into main.

The release contains desktop/mobile usability fixes and performance improvements. Detailed automated, production Sandbox and performance evidence is maintained in the [UI validation record](../design-plans/2026-10-20-ui-usability-validation.md).

The release gate requires Node 22 dependency installation, lint, all 405 tests, TypeScript/production build, documentation links and whitespace checks. Both main CI platforms must pass before tagging. The three release assets must be downloaded and SHA-256 verified before normal main-to-adv synchronization; adv CI must then pass. Final release identity and downloadable assets are recorded in [GitHub Release 6.13.1](https://github.com/threeyang3/bangumi-sync/releases/tag/6.13.1).

Preparation gate passed with 47 files / 405 tests and 51 documentation files checked. Dependency installation reported 7 development-toolchain advisories (4 moderate, 3 high); `npm audit --omit=dev` reported zero. Dependency versions are unchanged in this patch release.

Limitations: narrow desktop viewports are not physical mobile devices; network fixtures do not validate live-account writes. The performance comparison measures synchronous DOM/layout work and does not establish a universal speedup.
