复拍步骤：

1. 在隔离 Vault 部署同一 Release 的三个附件，启用插件，使用浅色主题。设置窗口选择“输出与命名／作品模板 → 动画”，保持默认模板与路径规则。
2. 为控制面板提供三条虚构音乐收藏，状态分别为听过、在听、想听；前两条已有同 ID 本地笔记，第三条未同步。客户端使用隔离演示响应，不发送账号请求。
3. 为音乐分类配置自定义模板，包含 `id: {{id}}`、`名称: {{name_cn}}`、`已购: false`、`渠道: 实体`。已有第一条笔记设置 `已购: true`、`渠道: 二手`。
4. 在真实面板勾选第一条，点击“更多 → 强制同步”，拍摄未修改的属性表单。直接确认后读回文件，验证旧值保留且正文确实由模板重新生成，再打开阅读视图拍摄结果。
5. 使用 Obsidian CLI 与 Electron 窗口 `capturePage` 捕获实际界面。设置页属于独立窗口，应按窗口标题定位；主窗口截图不能代替设置窗口。等待稳定帧，若截图仍是旧帧，调整窗口尺寸触发重绘后重新捕获。
6. 只裁切无关窗口区域，不修改产品文字、不隐藏错误，不合成运行状态。逐张查看成图，并按 README 约 740px 宽度及官网灯箱尺寸复核。
